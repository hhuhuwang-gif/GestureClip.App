# GestureClip v0.6.41 Beta

> 这是 v0.6.41 的性能优化覆盖版。请先退出旧进程，再覆盖安装。

## 本版重点

- **手势钩子独立线程**：鼠标事件不再阻塞 WPF UI，窗口忙碌时手势仍能及时响应
- **轨迹更新合帧**：约 24ms 刷新最新轨迹，快速拖动不再堆积大量 UI 更新
- **识别热路径瘦身**：距离判断改用平方值，减少高频浮点开方
- **普通右键更及时**：取消线程池排队后再恢复右键的额外等待
- **HUD 更轻**：去掉实时模糊阴影、冻结轨迹点集合，并阻止结束后的旧帧重新显示
- **剪贴板不易丢事件**：快速连续复制顺序处理，瞬时读取失败有限重试，图片复制路径补强
- **列表批量更新**：搜索、筛选结果一次提交，减少 WPF 集合通知风暴
- **剪贴板面板空闲预热**：启动首屏完成后预创建窗口、预载最近记录，首次唤出更快
- **重复打开直接命中缓存**：历史未变化时不再重复查询数据库和重绑列表
- **刷新不中断操作**：检测到新复制内容时保留现有列表，后台完成更新后一次替换
- **透明窗口渲染减负**：移除大范围模糊阴影；淡入缩短到 70ms，后续打开不再重复播放

## 手势滑动进一步提速

- 移除未绑定手势的「去绑定」快捷按钮及点击交互
- 未绑定手势仅显示短暂红色提示，约 700ms 后自动隐藏
- 手势窗口全程保持鼠标穿透、不可聚焦，不再动态切换交互状态
- 删除绑定按钮相关属性通知和命令刷新，减少每个方向变化时的 UI 工作
- 工位统计只在手势完成后刷新，不再与轨迹绘制争抢 UI 线程
- 轨迹坐标直接按虚拟桌面原点换算，移除逐点 PointFromScreen 调用

## 剪贴板兼容补强

- 超过 5MB 的有效图片改为自动缩放后保存，不再直接丢弃
- 新增 JPEG/JFIF、GIF、TIFF、DIBV5、图片文件复制、HTML 内嵌图片等读取路径
- 新增 UTF8_STRING、text/plain、StringFormat、CSV、RTF 等文字格式回退
- Office、浏览器和截图工具占用剪贴板时，读取重试窗口由 30ms 扩展到约 355ms
- 修复 4–8 位普通数字被误判成验证码而不进入历史的问题
- 图片同时带有 URL/替代文字时，优先保存真实图片而不是只保存文字

## 安装包

- GestureClip-v0.6.41-beta-win-x64.zip（便携版）
- GestureClip-Setup-v0.6.41-beta-win-x64.zip（安装版）
- SHA256SUMS.txt

## 覆盖更新

1. 托盘退出 GestureClip，任务管理器确认没有 GestureClip.exe
2. 下载新包并覆盖旧程序目录，或运行 Setup
3. 历史、设置与统计保存在 %LOCALAPPDATA%\GestureClip\，覆盖程序不会删除
4. 打开工位小熊 Hub，右上角应显示 **v0.6.41 · 本地**
