# GestureClip v0.6.41 Beta

## 必读：如何看到变化

1. **托盘退出** GestureClip（任务管理器确认无 GestureClip.exe）
2. 下载本版 zip 解压，运行新的 `GestureClip.exe`
3. 打开**剪贴板历史**（Ctrl+`）与**工位小熊 Hub**，右上角应显示 **v0.6.41 · 本地**
4. 浮层（剪贴板 / 快捷动作 / 设置 / Hub）已去掉透明窗口与重型阴影：Win11 下呈现系统 Mica 圆角背景，Win10 自动回退纯色面板

若仍像旧版：你还在跑旧进程，或打开的是旧路径 exe。

## 本版亮点（性能与轻量视觉）

- **全新设计系统**：剪贴板、Settings 首页、工位小熊 Hub、手势 HUD 全面换用 iOS 风格语义色板（浅色 / 深色）与统一间距 / 圆角 / 排版，去重卡片套卡片与行内四按钮
- **剪贴板浮层重做**：单 Surface 列表 + 「⋯」行内更多菜单（粘贴 / 复制 / 固定 / 删除 / 文本工具 / 二维码），6 段筛选、44px 搜索框、72×46 异步缩略图
- **手势 HUD 极简化**：方向块 + 动作名 + 快捷键 + 工作状态，120ms 入场动画
- **Settings 首页重做**：核心功能 3 卡直达、今日收益统计、功能地图、版本亮点卡（版本号动态读取）
- **Hub 重做**：紧凑状态卡（今日已赚 / 距下班 / 进度环）、快捷操作卡（摸鱼 / 冲刺 / 休息提醒 / 今日报告）、本周动作柱图
- **性能**：浮层全面轻量化（无透明窗口 + 重型阴影），列表批量绑定，启动预热改数据层，后台轮询自动暂停；新增「热键 → 首帧 / 可交互」耗时日志（`ClipboardPerf HotkeyToFirstFrameMs` / `HotkeyToInteractiveMs`）
- **精确回声抑制**（0.6.40 起）：复制与本机刚粘贴 / 写回的内容不再产生重复记录
