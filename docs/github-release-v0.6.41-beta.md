# GestureClip v0.6.41 Beta

## 必读：如何看到变化

1. **托盘退出** GestureClip（任务管理器确认无 GestureClip.exe）
2. 下载本版 zip 解压，运行新的 `GestureClip.exe`
3. 打开**剪贴板历史**（Ctrl+`）与**工位小熊 Hub**，右上角应显示 **v0.6.41 · 本地**
4. 浮层（剪贴板 / 快捷动作 / 设置 / Hub）已去掉透明窗口与重型阴影：Win11 下呈现系统 Mica 圆角背景，Win10 自动回退纯色面板

若仍像旧版：你还在跑旧进程，或打开的是旧路径 exe。

## 本版亮点（性能与轻量视觉）

- **浮层全面轻量化**：剪贴板 / 快捷动作 / 设置 / Hub 移除透明窗口 + 重型 DropShadow（BlurRadius 18~40 共 9 处），改用 Win11 Mica 系统背景，打开 / 拖动 / 滚动不再触发整窗软件渲染
- **列表批量绑定**：搜索 / 翻页 / 筛选改为单次批量刷新（50 条一次 Reset），输入与首帧响应明显变快
- **条目模板瘦身**：历史列表从重卡片改轻量分组行，滚动更流畅；9 个行内样式提取为共享资源
- **启动预热改数据层**：冷启动不再预建完整界面树，改为后台预取历史数据，无突发卡顿
- **后台轮询自动暂停**：Hub、小熊挂件、设置诊断在窗口隐藏时停止定时器，空闲零空转
- **精确回声抑制**（0.6.40 起）：复制与本机刚粘贴 / 写回的内容不再产生重复记录
