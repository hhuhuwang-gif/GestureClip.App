# GestureClip v0.6.37 Beta

## 必读：如何看到变化

1. **托盘退出** GestureClip（任务管理器确认无 GestureClip.exe）
2. 下载本版 zip 解压，运行新的 `GestureClip.exe`
3. 打开 **工位小熊 Hub**，右上角应显示 **v0.6.37 · 本地**
4. 主区应看到 **蓝/绿/琥珀三块指标砖**

若仍像旧版：你还在跑旧进程，或打开的是旧路径 exe。

## 本版亮点

- Hub 顶栏产品条 + 版本徽章
- 三色指标砖 + 更宽窗口
- 含 0.6.35 未绑定「去绑定」

## 安装包

- `GestureClip-v0.6.37-beta-win-x64.zip`（推荐）
- `GestureClip-Setup-v0.6.37-beta-win-x64.zip`
- `SHA256SUMS.txt`
