# GestureClip v0.6.45 Beta

本版汇总自 v0.6.43 之后的全部改动：滚动顺滑度、窗口行为、手势 HUD 视觉、设置界面精修、启动与构建流程。

## 滚动流畅度

- 设置窗口不再使用分层（`AllowsTransparency=True`）窗口。分层窗口会被 WPF 强制软件渲染，整窗每帧由 CPU 重绘，这是四个常用界面滚动一卡一卡的根本原因。
- 改为普通 DWM 合成窗口并交给 `WindowChrome` 处理窗口框架，滚动恢复到显示器刷新率（实测平均帧间隔由 18~20ms 降到 16~17ms）。
- 滚轮按下后立即提交首帧位移，不再等待下一个渲染帧——原先有 17~27ms 的空档，随后一次大跳，手感上就是"顿一下再滑"。
- 文本改用 `Display` 排版、灰度抗锯齿与固定 hinting，滚动期间不再逐帧重新 hint 字形。

## 滚动回弹修复

- 滚轮输入统一累积到目标偏移，反向滚动不再丢弃已累积的行程（实测下滚三格再上滚一格，落点由错误的 49px 修正为 96px）。
- 滚动帧单调逼近目标且不越界；内容高度变化只重新夹取目标，不中断动画。
- 拖动滚动条、键盘翻页、`BringIntoView` 与代码定位会立即接管滚动目标，不会被残留动画拉回。
- 关闭状态的 `ComboBox` 不再吞掉滚轮；滚动条改为胶囊滑块。

## 手势 HUD：数码方块流动渐变

- 手势提示卡片重做为分层结构：深空蓝底 + 氛围光 + 飘移液体光 + 像素底纹 + **方块流动渐变** + 斜向副数据流 + 扫描光柱 + 镜面高光。
- 方块渐变用 `DrawingBrush` 画出不透明方块作为 `OpacityMask`，让青→靛→紫→品红的渐变只存在于方块内部。
- 流动用 `SpreadMethod="Repeat"` 加首尾同色实现：平移一个渐变周期正好无缝循环，主带 18s 横向、副带 26s 斜向反向，交汇处颜色层次更丰富。
- 标题加 2×2 渐变色块图标与 1px 渐变分隔线；XP 条改为分段 LED 方块，填充色仍跟随主题强调色。
- 持续动画统一降到 15fps，避免分层窗口中多条动画叠加拖高 CPU。

## 设置界面

- 卡片描边改为顶部受光、底部收暗的渐变细边，配合范围更大更淡的投影，白色卡片与底色层次更分明。
- 左侧导航选中态改为渐变胶囊 + 受光细边，悬停时边框转为主色浅描边。
- 内容区底色整体调冷约 4%，分组列表容器统一同一套描边与轻阴影。
- 图片缩略图缓存上限由 128 张、解码宽 320px 调整为 64 张、256px，列表位图内存约减半。

## 启动与构建

- `Start-GestureClip.bat` 改为选项式启动器：检测到源码比可执行文件新时提供「快速 Debug 编译 / 完整重建发布包 / 仍启动旧版本」三选项，不再静默启动旧版本。
- 新增 `--quick`、`--rebuild`、`--no-check`、`--help` 开关，其余参数原样转发给 `GestureClip.exe`。
- 新增 `--trace-ui`：按需输出设置窗口构造、首次显示与页面切换耗时，便于定位启动与切页热点。
- 产物清理改走 `Remove-BuildOutput`，在被系统策略改为回收站删除的环境下也能稳定完成发布。

## 窗口行为

- 最大化改用 `WM_GETMINMAXINFO` 约束到显示器工作区，不再遮挡任务栏。
- 窗口圆角交给系统：Win11 由 DWM 裁圆角并保留投影，其余系统为直角，避免为圆角付出全窗裁剪成本。

## 诊断

- `--trace-scroll` 现在会先输出渲染层级（`tier` / `mode` / 是否分层窗口），并按次滚动汇总 `frames / avg / max / layout`，慢帧单独标记位置。
- 每帧日志改为按需开启（`FrameLogging`），避免日志同步写盘把测量结果本身拖慢。

## 下载与更新

- `GestureClip-Setup-v0.6.45-beta-win-x64.zip`：推荐安装包，解压后双击 `Setup.cmd`。
- `GestureClip-v0.6.45-beta-win-x64.zip`：便携包，解压后运行 `GestureClip.exe`。
- `SHA256SUMS.txt`：下载文件校验。
- 覆盖更新前请从托盘退出旧程序；历史、设置与统计保存在 `%LOCALAPPDATA%\GestureClip\`，更新程序不会删除。
- 历史条目的绿色状态表示本会话已复制，重启后清空该状态。

## 验证与限制

- 自动化测试、便携包、安装包和 SHA256 校验由发布流水线验证。
- 滚动帧率取决于显卡与显示器刷新率；60Hz 屏上 16.7ms 为上限。
- 自动化测试不代表真实 Office 粘贴实测；未配置代码签名证书时，Windows SmartScreen 可能提示未知发布者。
