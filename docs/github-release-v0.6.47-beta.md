# GestureClip v0.6.47 Beta

本版聚焦「观感统一 + 可测量的性能」：手势宏录制与手势触发播放、轨迹响应优化、HUD 动效强度分档与强调色跟随、一键启动与性能诊断。

## 手势宏与轨迹响应

- 新增宏录制与「用手势触发播放」：录制过程有独立状态窗，录好的宏可绑定到手势一键回放。
- 长宏与自然方向手势（Chevron）识别更准，鼠标抖动不再被误判为方向切换。
- 鼠标轨迹采样独立并按移动速率自适应，HUD 拖尾帧拆分到独立服务渲染，快速划动时轨迹跟手、不丢采样点。

## 手势 HUD：动效强度与强调色

- 新增「动效强度」三档（完整 / 均衡 / 极简）：均衡档把方块流动层降到 10fps；插拔电源自动跟随（电池供电 8fps 并关闭斜向副流）；极简档只保留静态渐变，零渲染开销。
- HUD 跟随强调色：设置里选了强调色后，方块流动层与扫描光柱用强调色重新生成，可无缝平移；未选时保持青紫默认配色。
- 动效统一走「先取消、再按条件重启」：窗口隐藏、切强度、切到电池都复用同一条取消逻辑，不残留动画。

## 启动与构建

- `Start-GestureClip.bat` 改为一键启动：产物新鲜就直接启动（约 1 秒），源码更新则静默做一次增量 Release 编译再启动；编译失败才停住并打印日志。新增 `--packaged`、`--publish`，`--no-build` 取代 `--no-check`，旧菜单保留在 `--ask` 后面。
- `build-setup.ps1` 新增 `-RequireSetup`，`release.yml` 改用该参数：本机或缺 Inno Setup 时直接失败，不再产出没有 `Setup.exe` 的 release。

## 性能诊断

- 新增 `--trace-mem`：每 15 秒输出工作集、私有内存、托管堆、堆碎片、缩略图缓存条目数、窗口数、句柄与线程数。
- 新增 `scripts/check-ui-performance.ps1`：多次采样并按预算判定启动、设置窗构建、首次显示与最慢切页耗时，超预算返回非零；CI 中通过仓库变量 `RUN_UI_PERF=true` 启用。
- 启动路径补全分段埋点，可把 `starting → started` 完整拆到毫秒，便于定位启动热点。

## 界面细节

- 剪贴板浮层与各深色弹窗的描边改为顶部受光、底部隐没的渐变细边（`BrushCardRimDark`），与设置页浅色卡片统一。
- 浮层预热后的关闭改为只 `Hide()`，再次打开复用同一实例，不再重建 XAML。

## 下载与更新

- `GestureClip-Setup-v0.6.47-beta-win-x64.zip`：推荐安装包，解压后双击 `Setup.cmd`。
- `GestureClip-v0.6.47-beta-win-x64.zip`：便携包，解压后运行 `GestureClip.exe`。
- `SHA256SUMS.txt`：下载文件校验。
- 覆盖更新前请从托盘退出旧程序；历史、设置与统计保存在 `%LOCALAPPDATA%\GestureClip\`，更新程序不会删除。
- 历史条目的绿色状态表示本会话已复制，重启后清空该状态。
