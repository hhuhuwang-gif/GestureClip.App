# 办公快捷操作

## 找到内容直接粘贴

1. 默认 `Ctrl + 反引号` 打开历史，输入关键字或拼音首字母。
2. 搜索框内 `↑` / `↓` 切换结果；`Enter` 粘贴并关闭。
3. `Shift + Enter` 去掉 HTML 标签后粘贴纯文本；`Ctrl + Enter` 粘贴后保留面板，`Ctrl + Shift + Enter` 是对应的纯文本模式。
4. `Alt + 1～9/0` 直接粘贴前十项，搜索框保持正常输入数字。

快速输入后马上粘贴，会完成当前查询再选择内容。没有匹配项时不会隐藏面板或粘贴旧条目。

## 分类、常用话术和附件

| 操作 | 面板内快捷键 |
| --- | --- |
| 全部 / 置顶 / 收藏 / 文字 / 图片 / 链接 | `Ctrl + 1～6` |
| 下个 / 上个分类 | `Ctrl + Tab` / `Ctrl + Shift + Tab` |
| 置顶 / 收藏 | `Ctrl + P` / `Ctrl + S` |
| 编辑记录 | `Ctrl + E`；列表聚焦时也可 `F2` |
| 合并复制多条文字 | 多选后 `Ctrl + C` |
| 纯文本复制 | `Ctrl + Shift + C` |
| 文字或图片复制为文件 | `Ctrl + Shift + F`，再到邮件或文件夹粘贴附件 |
| 粘贴队列 | 多选后 `Ctrl + Q`，在目标应用依次按 `Ctrl + V` |
| 聚焦搜索 / 快捷键说明 | `Ctrl + F` / `F1` |

图片仍一次复制一张，文字与图片不能混合批量复制。编辑器或二维码打开时保留其键盘操作，`Esc` 关闭当前编辑器。

## 手势配合

默认右键上划复制，下划粘贴，下左粘贴并回车；按住右键滚动滚轮切换标签页。按已有习惯在设置中修改动作绑定。

手势识别减少重复轨迹读取和临时数组，识别阈值与超时保持不变。剪贴板写入完成即进入后续复制/粘贴步骤，移除原固定 60 / 70ms 等待；窗口让焦点回到目标软件的等待仍保留。

历史查询、拼音/正则匹配和文件导出在后台执行。智能搜索候选按历史版本和分类复用；加载下一页只添加新记录，保留当前多选。

以上为程序执行路径与自动化回归确认的改动；不同办公软件的真实输入响应仍需桌面交互验证。

### 纯文本快捷键的目标与失败行为（未发布）

`Ctrl + Shift + V` 捕获触发时的目标窗口，等待焦点和相关按键释放后读取、净化并写入剪贴板，再向原目标粘贴。不再叠加触发层60ms和写入后70ms固定等待。窗口失焦、写入失败或输入发送失败时记录错误，不会自动重发Ctrl+V；没有可净化文字时仍保留原来的普通粘贴行为，但同样校验目标。
