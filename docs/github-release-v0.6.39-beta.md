# GestureClip v0.6.39 Beta

## 必读：如何看到变化

1. **托盘退出** GestureClip（任务管理器确认无 GestureClip.exe）
2. 下载本版 zip 解压，运行新的 `GestureClip.exe`
3. 打开 **工位小熊 Hub**，右上角应显示 **v0.6.39 · 本地**
4. Hub 卡片应有玻璃质感：顶部亮边、内部光泽、背景柔和色晕

若仍像旧版：你还在跑旧进程，或打开的是旧路径 exe。

## 本版亮点

- **节假日倒计时**：Hub 顶部显示距周末 / 距下一个法定节假日（本地内置 2026–2027 假日表）
- **今日已赚秒级跳动**：工作时段内已赚金额与下班倒计时每秒实时跳动
- **连续工作活动驱动**：离开电脑 ≥5 分钟自动算休息；休息中不弹提醒（只读键鼠空闲时长，不识别应用）
- **加班统计**：过点还在干活显示「已加班 X · 约白送老板 ¥Y」
- **滚轮手势**：按住右键滚滚轮切标签（可改动作 / 可关，连发不弹菜单）
- **以文件形式复制**：历史条目一键变 .txt / .png 文件，直接粘贴到文件夹
- **就地编辑**：F2 或右键编辑历史条目，直接覆盖原记录
- **二维码分享**：文本条目本机生成二维码，手机扫码带走
- **贴图置顶**：历史图片一键贴到桌面置顶（拖动 / 缩放 / 双击关闭）
- **小熊迷你挂件**：桌面常驻已赚 + 倒计时小胶囊，可换自定义桌宠 GIF
- **Hub 液态玻璃视觉升级**：镜面高光描边（rim light）、卡片内部光泽（sheen）、背景蓝 / 紫 / 青环境色晕
- **圆角体系升级**：状态大卡 24、分区卡片 20、指标砖 18、按钮与输入控件 10
- 阴影更柔更漫射；亮 / 暗双主题均已调校
- 修复：暗色主题无 Mica 回退时窗口背景误用浅色
