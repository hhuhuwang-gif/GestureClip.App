# 办公功能与响应测量

## 使用

- 剪贴板面板中多选后加入顺序队列，在目标应用按 Ctrl+V 逐条粘贴。只有成功发送粘贴后才移除队首。
- 队列失败时当前项保留，面板显示具体错误；点击“重试”重新准备快捷键，再回到目标应用按 Ctrl+V。点击“跳过”只移除失败项，“取消队列”恢复普通 Ctrl+V。
- 打开历史面板前先点击目标输入框。面板粘贴会恢复该窗口并检查按键释放；目标消失或激活失败会显示错误，不把失败标记为已粘贴。
- 拼音首字母和 `re:` 正则搜索扫描完整历史，200 是扫描批大小，不是历史搜索范围。扫描时显示进度；历史中途变化时需重新搜索。
- “设置 → 手势 → 按应用配置手势”中选择准确进程名，如 `EXCEL.exe`。只覆盖列出的动作和绑定模式；移除覆盖即继承全局，“未绑定”明确禁用该应用的对应手势。模板不会自动启用。

## 真实响应测量

在桌面空闲、剪贴板面板关闭时运行，进程号必须属于本工作区构建：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\scripts\measure-office.ps1 -GestureClipProcessId <进程号> -Samples 5
```

脚本只新建专用空白 Office 文档、使用独立浏览器临时配置和本地输入页。完成后关闭这些自建文档/窗口，恢复剪贴板、鼠标和原前台窗口。错误和清理失败会明确报错。原始结果位于 `artifacts/desktop-response/<时间>/measurements.csv` 和 `.json`，不记录用户文档或剪贴板正文。

测量包括热键到面板可见、面板确认到目标正文实际变化、鼠标抬起到目标正文实际变化。轮询和 Office COM / 浏览器回读存在观测开销，结果不能直接当作纯应用内部执行耗时。聊天软件不发送消息或修改现有草稿，因此不列为已验证应用。
