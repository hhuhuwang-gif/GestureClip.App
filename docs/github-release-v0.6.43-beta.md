# GestureClip v0.6.43 Beta

## 粘贴速度与稳定性

- 纯文本粘贴等待目标窗口真实获得焦点，并等待 Enter、V 和修饰键释放后再发送粘贴。
- 移除全局快捷键 60ms 和粘贴服务 70ms 的固定等待，所有分支传递打开面板前捕获的目标窗口。
- 剪贴板写入或输入注入失败时直接显示错误，不再盲目重发 Ctrl+V，避免粘贴旧内容或重复输入。
- 修复图片缓存键冲突造成不同截图显示旧预览的问题。

## 快捷动作中心

- 升级为冷灰蓝玻璃双栏布局，动作搜索、结果预览和执行区更清晰。
- `Shift+Enter` 预览、`Enter` 复制结果、`Ctrl+Enter` 处理并粘贴、`F5` 重新读取剪贴板。
- 无搜索结果和处理中状态明确可见；动作运行时同步禁用其他执行按钮。

## 应用手势与界面

- 应用手势配置升级为双栏界面，现有配置打开后自动选中。
- 支持复制应用配置为未启用草稿，通过方向按钮快速编写手势码。
- 新增 `Ctrl+N`、`Ctrl+D`、`Ctrl+O`、`Ctrl+S`、`Insert`、`Delete`、`Esc` 键盘路径。
- 粘贴队列区分正常和失败状态，失败时明确提供重试、跳过和取消。
- 应用配置、快捷动作与休息提醒支持浅色/深色主题，修复深色模式白底白字。

## 下载与更新

- `GestureClip-Setup-v0.6.43-beta-win-x64.zip`：推荐安装包，解压后双击 `Setup.cmd`。
- `GestureClip-v0.6.43-beta-win-x64.zip`：便携包，解压后运行 `GestureClip.exe`。
- `SHA256SUMS.txt`：下载文件校验。
- 覆盖更新前请从托盘退出旧程序；历史、设置与统计保存在 `%LOCALAPPDATA%\GestureClip\`，更新程序不会删除。
- 历史条目的绿色状态表示本会话已复制，重启后清空该状态。

## 验证与限制

- 自动化测试、便携包、安装包和 SHA256 校验由发布流水线验证。
- 自动化测试不代表真实 Office 粘贴实测；未配置代码签名证书时，Windows SmartScreen 可能提示未知发布者。
