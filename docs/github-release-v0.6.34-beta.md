# GestureClip v0.6.34 Beta

## 推荐安装（便携）

1. 下载 `GestureClip-v0.6.34-beta-win-x64.zip`
2. **先退出旧进程**，再解压双击 `GestureClip.exe`

## 本版亮点

- **手势浮层中文清晰**：YaHei + Grayscale，统计改 chip（手势/复制/粘贴/少点）
- 含 0.6.33/0.6.32 Hub 与 HUD 可读性改进

## 安装包

- `GestureClip-v0.6.34-beta-win-x64.zip`（推荐）
