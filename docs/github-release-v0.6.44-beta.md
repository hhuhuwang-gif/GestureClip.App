# GestureClip v0.6.44 Beta

## 设置页滚动回弹修复

- 修复首页、剪贴板、手势、动作绑定四个常用界面在快速上下滚动时的回弹：滚轮输入统一累积到同一个目标偏移，反向滚动不再丢弃尚未走完的行程。
- 实测下滚三格再上滚一格，落点由错误的 49px 修正为 96px；滚动帧严格单调逼近目标，不越界、不反向跳变。
- 内容高度变化（文字换行、滚动条出现）只重新夹取目标偏移，不再中断正在进行的滚动动画。
- 拖动滚动条、键盘翻页、`BringIntoView` 与代码定位会立即接管滚动目标，不会被残留动画拉回原位置。
- 关闭状态的 `ComboBox` 不再吞掉滚轮；在控件上滚动统一交给页面，速度与页面一致。

## 滚动性能

- 移除滚动热路径上每帧的字符串拼接，降低软件渲染下的 GC 压力。
- 到达边界后不再提交无效布局，收敛阈值调整为 1px，减少滚动尾部的无意义重绘。
- 高刷新率屏幕上限制重复布局，滚轮事件不再逐次遍历视觉树。

## 界面

- 滚动条改为胶囊滑块，悬停与拖动分别加深，浅色/深色主题都能看清。
- 修复列表项悬停色硬编码导致深色主题对比度异常的问题。
- 设置页内容区改为更冷的底色，白色卡片层次更清晰。
- 左侧导航选中项增加强调色指示条与主色文字，当前位置更容易辨认。

## 下载与更新

- `GestureClip-Setup-v0.6.44-beta-win-x64.zip`：推荐安装包，解压后双击 `Setup.cmd`。
- `GestureClip-v0.6.44-beta-win-x64.zip`：便携包，解压后运行 `GestureClip.exe`。
- `SHA256SUMS.txt`：下载文件校验。
- 覆盖更新前请从托盘退出旧程序；历史、设置与统计保存在 `%LOCALAPPDATA%\GestureClip\`，更新程序不会删除。
- 历史条目的绿色状态表示本会话已复制，重启后清空该状态。

## 验证与限制

- 自动化测试、便携包、安装包和 SHA256 校验由发布流水线验证。
- 设置窗口为圆角透明窗口（软件渲染），滚动帧率低于不透明窗口属预期取舍。
- 自动化测试不代表真实 Office 粘贴实测；未配置代码签名证书时，Windows SmartScreen 可能提示未知发布者。
