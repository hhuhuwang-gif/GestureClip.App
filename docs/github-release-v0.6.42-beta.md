# GestureClip v0.6.42 Beta

## 手势 HUD 渐变设计

- 右键手势浮层采用整面低饱和蓝绿渐变、柔光和高光细边，移除左侧装饰色条。
- 不透明底色避免背景文档透字，突出动作、方向和快捷键；保留统计与鼠标穿透。
- 识别中、未绑定、可执行动作分别提示，不改变手势执行时序。

## 办公便捷性与响应优化

- 顺序粘贴仅在成功后移除队首；失败暂停并保留当前项，支持重试、跳过或取消。
- 图片预览后台读取，切换选中项取消旧请求，同一历史版本复用缩略图请求。
- 拼音首字母、正则搜索分批扫描完整历史，展示进度及错误提示。
- 粘贴等待目标窗口真实焦点及相关按键释放，移除面板、手势和队列的固定等待。
- 支持按应用配置手势；未覆盖动作继承全局配置，办公模板默认不启用。

## 下载与覆盖更新

- `GestureClip-Setup-v0.6.42-beta-win-x64.zip`：解压后双击 `Setup.cmd` 安装。
- `GestureClip-v0.6.42-beta-win-x64.zip`：便携版，解压后运行 `GestureClip.exe`。
- `SHA256SUMS.txt`：下载文件校验。
- 更新前从托盘退出旧程序；历史、设置与统计保存在 `%LOCALAPPDATA%\GestureClip\`，覆盖程序不会删除。
- 历史条目的绿色状态表示本会话已复制，重启后清空该状态。

## 验证与限制

- 自动化测试与发布包检查由发布流水线执行，具体结果见本版本 GitHub Actions。
- 已提供 Word、Excel、独立浏览器测量脚本；真实 Office 粘贴兼容性及延迟测量尚未完成，不将自动化测试视为实测提速结果。
- 未配置代码签名证书时，Windows SmartScreen 可能提示未知发布者。
