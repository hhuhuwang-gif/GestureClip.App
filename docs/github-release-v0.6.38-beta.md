# GestureClip v0.6.38 Beta

## 必读：如何看到变化

1. **托盘退出** GestureClip（任务管理器确认无 GestureClip.exe）
2. 下载本版 zip 解压，运行新的 `GestureClip.exe`
3. 打开 **工位小熊 Hub**，右上角应显示 **v0.6.38 · 本地**
4. 打开剪贴板面板（Ctrl + `），在搜索框输入数字：应正常输入，不会跳转粘贴

若仍像旧版：你还在跑旧进程，或打开的是旧路径 exe。

## 本版亮点

- **修复**：搜索框输入数字不再直接按序号粘贴并关窗；? / Delete / Home / End 也不再误触
- **搜索增强**：拼音首字母（wx→微信）、`re:` 正则、🔗 链接筛选（Ctrl+6）、搜索时 ↑/↓ 选条目
- **数字快捷粘贴新逻辑**：列表聚焦时 1~9/0，任何时候 Alt+数字
- **文本工具**：右键记录转大小写 / 去空白 / JSON 格式化压缩 / URL 解码
- 面板淡入动画、卡片悬停高亮

## 安装包

- `GestureClip-v0.6.38-beta-win-x64.zip`（推荐）
- `GestureClip-Setup-v0.6.38-beta-win-x64.zip`
