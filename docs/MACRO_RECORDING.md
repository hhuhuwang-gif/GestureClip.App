# 快捷操作宏

设置左侧「录制」或首页「快捷操作宏」进入录制页；托盘「快捷操作宏（录制 / 回放）」打开独立面板。录制页与独立面板复用同一界面，全局 F8 / F9 由服务统一注册；宿主窗口关闭后释放，冲突时明确显示失败原因。

- F8：开始录制，再按一次停止并保存。
- F9：按原时间顺序回放当前选择的宏。先切换到目标应用，再按 F9。
- Esc：回放时实际按下可立即中止。宏自身的 Esc 输入不会误触发中止。
- 按住右键画 `<`：开始录制；再次画 `<` 停止并保存。
- 按住右键画 `>`：回放当前选择的录制；回放中再次画 `>` 中止。
- 两种形状均可从上往下或从下往上画，需启用应用的鼠标手势。使用现有识别与黑名单设置，不另开鼠标监听线程。
- 「回放」按钮会先最小化当前窗口。独立置顶状态条不抢目标应用焦点，显示时间、已执行事件数量和事件进度；点击「中止」或实际按下 Esc 取消。

录制名称与全部事件保存为 `%LOCALAPPDATA%/GestureClip/macros/macro-*.json`。每次录制创建独立文件；可选择旧文件回放或打开文件夹管理。保存失败会显示错误，并保留本次录制供「保存本次录制」重试。

“已保存的录制”优先显示录制名称；未命名时显示“录制 · yyyy-MM-dd HH:mm:ss”，并附录制时间。文件路径继续作为选择标识，旧文件不重命名。列表异步分块读取元数据，不把每个文件的事件数组载入内存。元数据无效时明确显示错误与文件路径。

记录鼠标位置、按钮、滚轮、键盘扫描码及按下/松开的原始时序。回放使用绝对屏幕坐标，因此应保持原显示器布局、窗口位置和键盘输入法状态。普通权限程序不能向更高权限窗口注入输入。

F8 / F9 是保留控制键，不录入宏。面板内部操作和程序注入的输入不录入。输入钩子仅在主动录制或监听回放中止时运行，独立线程处理；回放也在后台执行，不阻塞界面线程。中止、失败或宏末尾仍有按下事件时，尝试释放对应按键与鼠标按钮，失败明确报告。

停止录制时，按原始按下/松开时间移除该右键控制手势的鼠标轨迹，保留同时发生的键盘输入及其时间。回放发送的输入带专用标识，经过现有鼠标钩子时直接传给目标程序，避免被识别为新的 `<` / `>` 控制；第三方注入输入的既有行为不变。

## 验证

MacroPlaybackTests 覆盖顺序、取消释放、鼠标释放时保持当前指针、输入失败传播、平衡事件、非法文件与 JSON 独立保存，并验证执行进度不包含清理事件、原始错误与清理错误均保留。
MacroPlaybackStatusTests 解析真实进度控件，在 STA Dispatcher 中执行与只读服务属性的绑定，覆盖状态条的启动崩溃。`ProgressBar.Value` 必须显式 `Mode=OneWay`。
开发预览使用临时数据库，已通过 F8 开始/停止、保存状态和真实 SendInput 文本输入验证；测试回放只用明确生成的临时测试宏，未回放用户实际工作记录。
